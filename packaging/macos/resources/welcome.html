Pi Pocket

This package installs Pi Pocket for your user only. It needs no admin password, and your own Node.js, if you have one, does not change.

  • Its own Node.js and the Pi Pocket launcher go in ~/Library/Application Support/Pi Pocket.
  • Pi Pocket.app and Pi Pocket (console).app go in the Applications folder of your home folder.
  • To start Pi Pocket each time you sign in, choose Customize on the Installation Type page.

If Pi Pocket runs, the installer stops it first. Work in progress continues when Pi Pocket starts again. Your data in ~/.pi-pocket stays.
