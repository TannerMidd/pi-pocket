Pi, on your phone.
And any browser.

Pi Pocket is a self-hosted web app for the Pi coding agent. Start a run from anywhere, share it with the people you work with, and let it keep going when the server restarts.

Made for phones

What you use most is a thumb's reach away, and back closes what opened last. Push notifications, dictation, and an icon on your home screen.

Built to share

Invite people, or open a session on all your devices. Everyone sees the run as it happens, and can steer it or talk beside it.

Survives restarts

Every step is stored before it shows. Restart the server mid-run, and the work picks up where it stopped.

Multiplayer

Share a session.

Everyone sees the run as it happens, and each message shows who sent it.

  • Presence. See who is here, and who is about to write to Pi.
  • Side chat. Talk beside the run, where Pi does not see it. @mention people, quote a reply, or pass a message on to Pi.
  • Take turns. One person drives; the others ask to. Anyone who can steer can still stop a run.
  • Invites. A link, a QR code, or a short code. Let people steer or only view, in one session or all of them.
PiP

An assistant for your other sessions.

PiP opens over whatever you are looking at. Ask in plain words, and it hands the work to a session with the tools to do it.

  • Starts work. In a folder, a git worktree, or a GitHub repository, now or on a schedule.
  • Reports back. It follows a run to the end and sums it up in a line, as a push notification when you are away.
  • Watches GitHub. "When CI fails on main, fix it and tell me."
  • Stays in its lane. It changes no files and runs no commands, never allows a call that waits for approval, and never picks a model.

Press Alt+A, tap the orb, or type /pip. Only the owner can open PiP.

Wide screens

Room for everything.

Your sessions, the conversation with each of Pi's edits, and peek tiles that show your other sessions at work. Answer an approval right from its tile.

Foundation

Built on Pi Durable.

Pi Durable is Earendil's harness for long-running agents. It keeps conversations, model calls, tool calls, and app state together, and commits each step before anything is shown. Pi Pocket keeps all of it in one SQLite file.

  • Runs survive restarts. A tool call that was cut off runs again only if that is safe; otherwise Pi is told it was interrupted.
  • Same view everywhere. Browsers get only committed state, so a device that joins late sees what everyone else sees.
  • Steer or queue. A message sent mid-run joins it or waits for the next one, across restarts too.

Security

You decide who can make Pi act.

Pi runs commands on your machine as you. Pi Pocket controls who can ask it to, and which calls wait for a person.

  • Lancet Guard. Once you turn it on, it checks every bash, write, and edit call. Risky ones wait for someone to allow or deny them, and the answer survives restarts.
  • Roles. Viewers can read, react, and chat, but cannot send to Pi, approve, or upload.
  • Text from outside is data. Webhooks, GitHub events, and what PiP reads reach Pi marked as data, not instructions.
  • Sandboxes. Artifacts and the built-in browser cannot reach the app or its cookies.

Access

Four ways to connect.

The launcher asks how your devices connect, then shows a sign-in link and a QR code for your phone.

local

This device

127.0.0.1, behind a tunnel of your own.

lan

Local network

Any device on the same network, over plain http.

cloudflare

Cloudflare Tunnel

A public https address, with no account needed.

tailscale

Tailscale

Only devices on your tailnet, encrypted by Tailscale.

Push notifications and dictation need https. Pi Pocket also runs on Android: install it in Termux and keep everything on the phone.

Get started

Run it yourself.

  1. Sign in with PiRun pi and use /login, or sign in later from the app.
  2. Start the launcherChoose how your devices connect. Your choice is remembered.
  3. Scan the QR codeYour phone stays signed in for a year. Add it to your home screen.
  4. Pick a modelTap the model chip in the message box, and make it the default. 
# Requires Node.js 22.19 or newer
$ npm install -g pi-pocket
$ pi-pocket
# Or try it once: npx pi-pocket
# To change its code: git clone, npm install, npm start
$ pkg update && pkg upgrade
$ pkg install nodejs git
$ npm install -g --ignore-scripts @earendil-works/pi-coding-agent
$ pi   # /login, then quit
$ git clone https://github.com/TannerMidd/pi-pocket.git
$ cd pi-pocket && npm install --ignore-scripts
$ termux-wake-lock && npm start
While the launcher runs: q quits, r restarts the server, a changes access, o opens a browser, and s shows the QR code. More in the README.
